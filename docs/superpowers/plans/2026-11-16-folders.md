# Folders Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Group sounds into one level of folders shown as tiles in the grid (desktop and phone), and let the user multi-select sounds and move them to a folder.

**Architecture:** Each sound gets an optional `folder` id; `Config` gets a `folders` list. Sounds keep one global order and a view (top level or a folder) is a filter over it, so `reorder_sounds` stays as is. The desktop UI keeps the open folder and the selection in the zustand store; pure helpers (`selection.ts`, `view.ts`, `drop.ts`, `shortcuts.ts`) hold the logic so it is unit tested without React. The phone page renders a mixed list of folder, Back and sound tiles from the same state message.

**Tech Stack:** Rust (soundboard-core, Tauri 2 shell), React 19 + zustand + @dnd-kit + Tailwind 4, Vitest + Testing Library, vanilla JS phone page.

Spec: `docs/superpowers/specs/2026-11-16-folders-design.md`.

## Global Constraints

- One level of folders. A sound is on the top level (`folder: None` / `null`) or in exactly one folder.
- Deleting a folder never deletes a sound; its sounds move to the top level.
- Folder names: trimmed, max 60 characters, empty becomes `Folder`. Duplicate names are allowed.
- Configs from 0.1.2 must load unchanged; `CONFIG_VERSION` stays `1`.
- Every config change is saved immediately (`App::mark_dirty` already flushes).
- Monochrome UI: folder tiles have no color of their own; amber (`accent`) only means playing; selection uses a white outline.
- Error message for a missing folder, everywhere: `That folder no longer exists`.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Test commands: `cargo test -p soundboard-core`, `cargo test -p soundboard`, `npm test`, `npm run build` (runs `tsc --noEmit`, which type-checks test files too).

pub const MAX_FOLDER_NAME: usize = 60;
pub const DEFAULT_FOLDER_NAME: &str = "Folder";
pub const NO_SUCH_FOLDER: &str = "That folder no longer exists";

/// A named group of sounds. One level only: folders never contain folders.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Folder {
    pub id: String,
    pub name: String,
}

/// Trimmed and at most `MAX_FOLDER_NAME` characters; an empty name becomes `DEFAULT_FOLDER_NAME`.
pub fn folder_name(raw: &str) -> String {
    let capped: String = raw.trim().chars().take(MAX_FOLDER_NAME).collect();
    let name = capped.trim_end();
    if name.is_empty() {
        DEFAULT_FOLDER_NAME.to_string()
    } else {
        name.to_string()
    }
}
```

    pub fn folder(&self, id: &str) -> Option<&Folder> {
        self.folders.iter().find(|f| f.id == id)
    }

    /// Adds a folder at the end and returns its id.
    pub fn create_folder(&mut self, name: &str) -> String {
        let id = uuid::Uuid::new_v4().to_string();
        self.folders.push(Folder { id: id.clone(), name: folder_name(name) });
        id
    }

    pub fn rename_folder(&mut self, id: &str, name: &str) -> Result<(), &'static str> {
        let folder = self.folders.iter_mut().find(|f| f.id == id).ok_or(NO_SUCH_FOLDER)?;
        folder.name = folder_name(name);
        Ok(())
    }

    /// Removes the folder; its sounds go to the top level. Never deletes a sound.
    pub fn delete_folder(&mut self, id: &str) -> Result<(), &'static str> {
        let idx = self.folders.iter().position(|f| f.id == id).ok_or(NO_SUCH_FOLDER)?;
        self.folders.remove(idx);
        for s in self.sounds.iter_mut().filter(|s| s.folder.as_deref() == Some(id)) {
            s.folder = None;
        }
        Ok(())
    }

    /// Puts each listed sound in `folder` (None = top level). Unknown sound ids are skipped.
    /// Returns how many sounds were moved; an unknown folder is an error and changes nothing.
    pub fn move_sounds(&mut self, ids: &[String], folder: Option<&str>) -> Result<usize, &'static str> {
        if let Some(f) = folder {
            if self.folder(f).is_none() {
                return Err(NO_SUCH_FOLDER);
            }
        }
        let mut moved = 0;
        for s in self.sounds.iter_mut().filter(|s| ids.contains(&s.id)) {
            s.folder = folder.map(str::to_string);
            moved += 1;
        }
        Ok(moved)
    }

    /// Drops duplicate folder ids, cleans names, and moves sounds whose folder is gone to the top level.
    fn sanitize_folders(&mut self) {
        let mut seen = HashSet::new();
        self.folders.retain(|f| seen.insert(f.id.clone()));
        for f in &mut self.folders {
            f.name = folder_name(&f.name);
        }
        for s in &mut self.sounds {
            if s.folder.as_ref().is_some_and(|f| !seen.contains(f)) {
                s.folder = None;
            }
        }
    }
```

```ts
/** Desktop multi-select: the selected sound ids plus the anchor that Shift+click ranges start from. */
export interface Sel { ids: ReadonlySet<string>; anchor: string | null }

export const NO_SELECTION: Sel = { ids: new Set(), anchor: null };

/** Ctrl+click: add or remove one sound; it becomes the anchor. */
export function toggle(sel: Sel, id: string): Sel {
  const ids = new Set(sel.ids);
  if (ids.has(id)) ids.delete(id);
  else ids.add(id);
  return { ids, anchor: id };
}

/**
 * Shift+click: select every sound from the anchor to `id` in `viewIds`, replacing the selection.
 * Without an anchor in this view it selects `id` alone and makes it the anchor.
 */
export function range(sel: Sel, id: string, viewIds: readonly string[]): Sel {
  const to = viewIds.indexOf(id);
  if (to < 0) return sel;
  const from = sel.anchor === null ? -1 : viewIds.indexOf(sel.anchor);
  if (from < 0) return { ids: new Set([id]), anchor: id };
  const [lo, hi] = from <= to ? [from, to] : [to, from];
  return { ids: new Set(viewIds.slice(lo, hi + 1)), anchor: sel.anchor };
}

export function selectAll(viewIds: readonly string[]): Sel {
  return { ids: new Set(viewIds), anchor: viewIds[0] ?? null };
}

/** Forgets ids that are not in `liveIds`. Returns `sel` itself when nothing changed. */
export function prune(sel: Sel, liveIds: ReadonlySet<string>): Sel {
  const anchorOk = sel.anchor === null || liveIds.has(sel.anchor);
  if (anchorOk && [...sel.ids].every((id) => liveIds.has(id))) return sel;
  return {
    ids: new Set([...sel.ids].filter((id) => liveIds.has(id))),
    anchor: anchorOk ? sel.anchor : null,
  };
}

/** The sounds an action on `id` applies to: the whole selection (in `orderedIds` order) when `id` is in it, else just `id`. */
export function targetIds(sel: Sel, id: string, orderedIds: readonly string[]): string[] {
  if (!sel.ids.has(id)) return [id];
  return orderedIds.filter((x) => sel.ids.has(x));
}

/** What a folder tile shows: how many sounds, the colors of the first four, and whether any is playing. */
export function summarize(sounds: readonly UiSound[], folderId: string, playing: ReadonlySet<string>): FolderSummary {
  const inside = viewSounds(sounds, folderId);
  return {
    count: inside.length,
    colors: inside.slice(0, 4).map((s) => s.color),
    playing: inside.some((s) => playing.has(s.id)),

import { closestCenter, pointerWithin, type CollisionDetection } from "@dnd-kit/core";

export const BACK_TARGET = "back";
const FOLDER_PREFIX = "folder:";

/** Droppable id of a folder tile; never collides with a sound id (uuid). */
export const folderTarget = (id: string) => FOLDER_PREFIX + id;

const isMoveTarget = (id: string) => id === BACK_TARGET || id.startsWith(FOLDER_PREFIX);

export type DropResult = { kind: "move"; folder: string | null } | { kind: "reorder"; overId: string } | null;

/** What dropping sound `activeId` on droppable `overId` means. */
export function resolveDrop(activeId: string, overId: string | null): DropResult {
  if (overId === null || overId === activeId) return null;
  if (overId === BACK_TARGET) return { kind: "move", folder: null };
  if (overId.startsWith(FOLDER_PREFIX)) return { kind: "move", folder: overId.slice(FOLDER_PREFIX.length) };
  return { kind: "reorder", overId };
}

/**
 * Folder and Back tiles are targets only while the pointer is inside them, so dragging past them
 * still reorders; everywhere else the nearest sound tile wins, as before.
 */
export const collision: CollisionDetection = (args) => {
  const moves = args.droppableContainers.filter((c) => isMoveTarget(String(c.id)));
  const hit = pointerWithin({ ...args, droppableContainers: moves });
  if (hit.length > 0) return hit;
  return closestCenter({ ...args, droppableContainers: args.droppableContainers.filter((c) => !isMoveTarget(String(c.id))) });
};

/** Window-level shortcuts. Dialogs and popovers catch their own Esc first (capture phase). */
export function handleGlobalKey(e: KeyLike) {
  if (isTypingTarget(e.target)) return;
  const st = useStore.getState();

type FolderMenu = { folder: UiFolder; x: number; y: number };
type Moving = { ids: string[]; x: number; y: number };

export function TileGrid() {
  const state = useStore((s) => s.state)!;
  const play = useStore((s) => s.play);
  const run = useStore((s) => s.run);
  const optimistic = useStore((s) => s.optimistic);
  const pendingTrimId = useStore((s) => s.pendingTrimId);
  const setPendingTrim = useStore((s) => s.setPendingTrim);
  const openFolder = useStore((s) => s.openFolder);
  const setOpenFolder = useStore((s) => s.setOpenFolder);
  const sel = useStore((s) => s.sel);
  const setSel = useStore((s) => s.setSel);
  const clearSel = useStore((s) => s.clearSel);

  const [menu, setMenu] = useState<Menu | null>(null);
  const [deleting, setDeleting] = useState<UiSound | null>(null);
  const [renaming, setRenaming] = useState<UiSound | null>(null);
  const [picking, setPicking] = useState<Menu | null>(null);
  const [capturing, setCapturing] = useState<UiSound | null>(null);
  const [trimming, setTrimming] = useState<UiSound | null>(null);
  const [dragOver, setDragOver] = useState(false);
  const [folderMenu, setFolderMenu] = useState<FolderMenu | null>(null);
  const [renamingFolder, setRenamingFolder] = useState<UiFolder | null>(null);
  const [deletingFolder, setDeletingFolder] = useState<UiFolder | null>(null);
  const [creatingFolder, setCreatingFolder] = useState(false);
  const [moving, setMoving] = useState<Moving | null>(null);
  /** Sounds waiting for the name typed into "New folder…" from the move picker. */
  const [newFolderFor, setNewFolderFor] = useState<string[] | null>(null);

  const sensors = useSensors(useSensor(PointerSensor, { activationConstraint: { distance: 6 } }));

  useEffect(() => {
    const unlisten = getCurrentWebview().onDragDropEvent((e) => {
      if (e.payload.type === "enter" || e.payload.type === "over") setDragOver(true);
      else if (e.payload.type === "leave") setDragOver(false);
      else if (e.payload.type === "drop") {
        setDragOver(false);
        void addPaths(e.payload.paths);
      }
    });
    return () => { void unlisten.then((f) => f()); };
  }, []);

  const allIds = state.sounds.map((s) => s.id);
  const view = viewSounds(state.sounds, openFolder);
  const viewIds = view.map((s) => s.id);

  const onDragEnd = (ev: DragEndEvent) => {
    const activeId = String(ev.active.id);
    const drop = resolveDrop(activeId, ev.over ? String(ev.over.id) : null);
    if (!drop) return;
    if (drop.kind === "move") {
      // Dragging a selected tile carries the whole selection.
      void moveTo(targetIds(sel, activeId, allIds), drop.folder);
    } else {
      // Moving within the global order keeps every other view's relative order intact.
      void run(api.reorderSounds(arrayMove(allIds, allIds.indexOf(activeId), allIds.indexOf(drop.overId))));
    }
  };

  const menuItems = (s: UiSound): MenuItem[] => {
    const ids = targetIds(sel, s.id, allIds);
    return [
      {
        label: ids.length > 1 ? `Move ${ids.length} sounds to folder…` : "Move to folder…",
        onSelect: () => menu && setMoving({ ids, x: menu.x, y: menu.y }),
      },
      { label: "Rename", onSelect: () => setRenaming(s) },
      { label: s.trim ? "Trim audio (trimmed)" : "Trim audio", onSelect: () => setTrimming(s) },
      { label: s.image_path ? "Change image" : "Set image", onSelect: () => void pickImageFor(s.id) },
      ...(s.image_path ? [{ label: "Remove image", onSelect: () => void run(api.clearSoundImage(s.id)) }] : []),
      { label: "Change color", onSelect: () => menu && setPicking({ sound: s, x: menu.x, y: menu.y }) },
      { label: s.hotkey ? "Change hotkey" : "Set hotkey", onSelect: () => setCapturing(s) },
      ...(s.hotkey ? [{ label: "Clear hotkey", onSelect: () => void run(api.clearHotkey(s.id)) }] : []),
      { label: "Delete", danger: true, onSelect: () => setDeleting(s) },
    ];
  };

  const folderItems = (f: UiFolder): MenuItem[] => [
    { label: "Rename", onSelect: () => setRenamingFolder(f) },
    { label: "Delete", danger: true, onSelect: () => setDeletingFolder(f) },
  ];

  const openMoveFromBar = (e: MouseEvent<HTMLButtonElement>) => {
    const r = e.currentTarget.getBoundingClientRect();
    setMoving({ ids: allIds.filter((id) => sel.ids.has(id)), x: r.left, y: r.bottom + 4 });
  };

  const noDevices = !state.devices.speakers && !state.devices.virtual_mic;

  if (state.sounds.length === 0 && state.folders.length === 0) {
    return (
      <div className="flex h-full flex-col">
        {noDevices && <Banner />}
        <div className="min-h-0 flex-1">
          <EmptyState dragOver={dragOver} />
        </div>
      </div>
    );
  }

  const playingSet = new Set([...state.playing, ...optimistic]);
  // A single import opens the editor once the new sound is in state.
  const imported = pendingTrimId ? state.sounds.find((s) => s.id === pendingTrimId) : undefined;

  return (
    <div className={cx("min-h-full rounded-md border border-transparent", dragOver && "border-accent")}>
      {noDevices && <Banner />}
      {sel.ids.size > 0 && <SelectionBar count={sel.ids.size} onMove={openMoveFromBar} onClear={clearSel} />}
      <DndContext sensors={sensors} collisionDetection={collision} onDragEnd={onDragEnd}>
        <SortableContext items={viewIds} strategy={rectSortingStrategy}>
          <div className="grid gap-2" style={{ gridTemplateColumns: "repeat(auto-fill, minmax(120px, 1fr))" }}>
            {openFolder === null
              ? state.folders.map((f) => (
                  <FolderTile
                    key={f.id}
                    folder={f}
                    summary={summarize(state.sounds, f.id, playingSet)}
                    onOpen={() => setOpenFolder(f.id)}
                    onContextMenu={(e) => { e.preventDefault(); setFolderMenu({ folder: f, x: e.clientX, y: e.clientY }); }}
                  />
                ))
              : <BackTile onBack={() => setOpenFolder(null)} />}
            {view.map((s) => (
              <Tile
                key={s.id}
                sound={s}
                playing={playingSet.has(s.id)}
                selected={sel.ids.has(s.id)}
                onPlay={() => void play(s.id)}
                onSelect={(mode) => setSel(mode === "toggle" ? toggle(sel, s.id) : range(sel, s.id, viewIds))}
                onVolume={(v) => void run(api.setSoundVolume(s.id, v))}
                onContextMenu={(e) => { e.preventDefault(); setMenu({ sound: s, x: e.clientX, y: e.clientY }); }}
              />
            ))}
            <button
              type="button"
              onClick={() => void pickAndAddSounds()}
              aria-label="Add sounds"
              title="Add sounds"
              className="flex aspect-square items-center justify-center rounded-md border border-dashed border-border text-3xl font-light text-mute outline-none ring-accent transition-colors hover:border-dim hover:text-dim focus-visible:ring-2"
            >
              +
            </button>
            {openFolder === null && <NewFolderTile onClick={() => setCreatingFolder(true)} />}
          </div>
        </SortableContext>
      </DndContext>

      {menu && <ContextMenu x={menu.x} y={menu.y} items={menuItems(menu.sound)} onClose={() => setMenu(null)} />}
      {folderMenu && <ContextMenu x={folderMenu.x} y={folderMenu.y} items={folderItems(folderMenu.folder)} onClose={() => setFolderMenu(null)} />}
      {moving && (
        <MovePicker
          x={moving.x}
          y={moving.y}
          count={moving.ids.length}
          folders={state.folders}
          current={openFolder}
          onPick={(folder) => void moveTo(moving.ids, folder)}
          onNewFolder={() => setNewFolderFor(moving.ids)}
          onClose={() => setMoving(null)}
        />
      )}
      {picking && (
        <ColorPicker
          x={picking.x}
          y={picking.y}
          current={picking.sound.color}
          onPick={(color) => void run(api.setSoundColor(picking.sound.id, color))}
          onClose={() => setPicking(null)}
        />
      )}
      {deleting && (
        <ConfirmDialog
          title={`Delete "${deleting.name}"? The file is removed from the soundboard.`}
          confirmLabel="Delete"
          danger
          onCancel={() => setDeleting(null)}
          onConfirm={() => { void run(api.deleteSound(deleting.id)); setDeleting(null); }}
        />
      )}
      {renaming && (
        <RenameDialog
          title="Name"
          initial={renaming.name}
          onCancel={() => setRenaming(null)}
          onSubmit={(name) => { void run(api.renameSound(renaming.id, name)); setRenaming(null); }}
        />
      )}
      {creatingFolder && (
        <RenameDialog
          title="New folder"
          initial=""
          onCancel={() => setCreatingFolder(false)}
          onSubmit={(name) => { void run(api.createFolder(name)); setCreatingFolder(false); }}
        />
      )}
      {newFolderFor && (
        <RenameDialog
          title="New folder"
          initial=""
          onCancel={() => setNewFolderFor(null)}
          onSubmit={(name) => { void moveToNewFolder(newFolderFor, name); setNewFolderFor(null); }}
        />
      )}
      {renamingFolder && (
        <RenameDialog
          title="Folder name"
          initial={renamingFolder.name}
          onCancel={() => setRenamingFolder(null)}
          onSubmit={(name) => { void run(api.renameFolder(renamingFolder.id, name)); setRenamingFolder(null); }}
        />
      )}
      {deletingFolder && (
        <ConfirmDialog
          title={`Delete folder "${deletingFolder.name}"? Sounds inside move to the top level.`}
          confirmLabel="Delete"
          danger
          onCancel={() => setDeletingFolder(null)}
          onConfirm={() => { void run(api.deleteFolder(deletingFolder.id)); setDeletingFolder(null); }}
        />
      )}
      {capturing && (
        <HotkeyCapture
          title={`Hotkey for "${capturing.name}"`}
          current={capturing.hotkey}
          onCancel={() => setCapturing(null)}
          onCapture={(accel) => { void run(api.setHotkey(capturing.id, accel)); setCapturing(null); }}
          onClear={capturing.hotkey ? () => { void run(api.clearHotkey(capturing.id)); setCapturing(null); } : undefined}
        />
      )}
      {trimming && <TrimEditor key={trimming.id} sound={trimming} mode="edit" onClose={() => setTrimming(null)} />}
      {imported && !trimming && <TrimEditor key={imported.id} sound={imported} mode="import" onClose={() => setPendingTrim(null)} />}
    </div>
  );
}
```

- [ ] **Step 2: Replace `render()` with a view-aware version**

In the script, replace the whole `function render() { ... }` with the following. The sound-tile creation and update code is the existing code, moved into `newSoundTile` and `syncSoundTile` unchanged except that each tile also gets `dataset.key`:

```js
  // Folder shown on the phone; page memory only, so a reload starts on the top level.
  let openFolder = null;
  function viewItems() {
    if (openFolder !== null && !state.folders.some((f) => f.id === openFolder)) openFolder = null;
    const items = [];
    if (openFolder === null) for (const f of state.folders) items.push({ key: "f:" + f.id, folder: f });
    else items.push({ key: "back" });
    for (const s of state.sounds) if ((s.folder ?? null) === openFolder) items.push({ key: s.id, sound: s });
    return items;
  }
  function openView(id) {
    openFolder = id;
    buzz();
    grid.parentElement.scrollTop = 0;
    render();
  }
  function newSoundTile(s) {
    const el = document.createElement("button");
    el.type = "button";
    el.className = "tile";
    el.dataset.id = s.id;
    el.dataset.key = s.id;
    el.addEventListener("click", () => {
      // The click that ends a long-press must not also play the sound.
      if (suppressClick) { suppressClick = false; return; }
      el.classList.add("playing"); buzz(); send({ type: "play", id: el.dataset.id });
    });
    wireLongPress(el);
    const name = document.createElement("span");
    name.className = "name";
    el.appendChild(name);
    // After the name so the color bar paints above the scrim and keeps its true color.
    const bar = document.createElement("span");
    bar.className = "bar";
    bar.setAttribute("aria-hidden", "true");
    el.appendChild(bar);
    return el;
  }
  function syncSoundTile(el, s, playing) {
    const wantImg = s.has_image ? `/img/${s.id}` : "";
    let img = el.querySelector("img");
    if (wantImg && !img) { img = document.createElement("img"); img.alt = ""; el.prepend(img); }
    if (!wantImg && img) img.remove();
    if (img && img.getAttribute("src") !== wantImg) img.src = wantImg;
    el.querySelector(".name").textContent = s.name;
    el.setAttribute("aria-label", s.name);
    el.style.setProperty("--c", s.color);
    decorate(el, s);
    el.classList.toggle("img", s.has_image);
    el.classList.toggle("playing", playing.has(s.id));
    syncSweep(el, s, playing.has(s.id));
  }
  function newFolderTile(f) {
    const el = document.createElement("button");
    el.type = "button";
    el.className = "tile folder";
    el.dataset.key = "f:" + f.id;
    el.dataset.folder = f.id;
    el.innerHTML = '<span class="pv" aria-hidden="true"><i></i><i></i><i></i><i></i></span><span class="fn"><b></b><small></small></span>';
    el.addEventListener("click", () => openView(el.dataset.folder));
    return el;
  }
  function syncFolderTile(el, f, playing) {
    const inside = state.sounds.filter((s) => s.folder === f.id);
    el.querySelector("b").textContent = f.name;
    el.querySelector("small").textContent = String(inside.length);
    el.setAttribute("aria-label", `${f.name}, ${inside.length} ${inside.length === 1 ? "sound" : "sounds"}`);
    el.querySelectorAll(".pv i").forEach((dot, i) => { dot.style.background = inside[i] ? inside[i].color : ""; });
    el.classList.toggle("playing", inside.some((s) => playing.has(s.id)));
  }
  function newBackTile() {
    const el = document.createElement("button");
    el.type = "button";
    el.className = "tile back";
    el.dataset.key = "back";
    el.setAttribute("aria-label", "Back");
    el.innerHTML = '<span aria-hidden="true">←</span>Back';
    el.addEventListener("click", () => openView(null));
    return el;
  }
  function render() {
    if (!state) return;
    if (!masterDragging) { master.value = state.master_volume; mpct.textContent = pct(state.master_volume); }
    const playing = new Set(state.playing);
    stop.classList.toggle("on", playing.size > 0);
    const items = viewItems();
    empty.classList.toggle("hidden", items.length > 0);
    // Drop tiles not in this view before the walk, so the cursor never rests on a stale
    // node (which would make every live tile after it look out of place and get moved).
    const live = new Set(items.map((it) => it.key));
    for (const el of [...grid.children]) if (!live.has(el.dataset.key)) el.remove();
    // Walk the grid in view order and move a node only when it is out of place: moving a
    // node restarts its CSS animations, which would reset every running sweep on each state push.
    let cursor = grid.firstElementChild;
    for (const it of items) {
      let el = grid.querySelector(`[data-key="${CSS.escape(it.key)}"]`);
      if (!el) el = it.sound ? newSoundTile(it.sound) : it.folder ? newFolderTile(it.folder) : newBackTile();
      if (it.sound) syncSoundTile(el, it.sound, playing);
      else if (it.folder) syncFolderTile(el, it.folder, playing);
      if (el === cursor) cursor = cursor.nextElementSibling;
      else grid.insertBefore(el, cursor);
    }
    syncSheet();
  }
```
