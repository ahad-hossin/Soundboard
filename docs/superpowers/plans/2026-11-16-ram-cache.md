# Less RAM for the decode cache — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Cut the app's RAM roughly in half or more by storing decoded audio as 16-bit and caching only the buffer that plays.

**Architecture:** `DecodedBuffer` stores `i16`; conversion to `f32` happens per sample at playback and inside DSP. The engine's LRU cache holds per-sound play buffers tagged with `(Option<Trim>, bass)`; a single editor slot holds the full decode while the trim editor is open.

**Tech Stack:** Rust (rodio 0.20), Tauri 2, React 19 + vitest.

Spec: `docs/superpowers/specs/2026-11-16-ram-cache-design.md`.

## Global Constraints

- Branch `feat/ram-cache`; never commit to `master`.
- Commit messages end with a blank line and `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

- f32 → i16 conversion: `(x.clamp(-1.0, 1.0) * 32767.0).round() as i16`; i16 → f32: `s as f32 / 32768.0`.
- `CACHE_BYTES = 200 * 1024 * 1024` after Task 2.

### Task 1: 16-bit sample storage

**Files:** `core/src/audio/backend.rs`, `decode.rs`, `rodio_backend.rs`, `trim.rs`, `bass.rs`, `engine.rs` (`sine`), `fake_backend.rs`, `cache.rs` tests, and any test that builds or inspects samples.

**Interfaces:**
- `DecodedBuffer { channels: u16, sample_rate: u32, samples: Arc<Vec<i16>> }`
- `DecodedBuffer::new(channels, sample_rate, Vec<f32>) -> Self` — converts with the global formula (kept so f32-producing code and tests stay simple).
- `DecodedBuffer::from_i16(channels, sample_rate, Vec<i16>) -> Self` — no conversion.
- `pub fn to_f32(s: i16) -> f32` (in backend.rs) — `s as f32 / 32768.0`; used by SharedSource, bass and waveform.
- `byte_len()` = `samples.len() * size_of::<i16>()`.

### Task 2: Cache only what plays, editor slot, budget 200 MB

**Files:** `core/src/audio/engine.rs`; `src-tauri/src/state.rs` (`CACHE_BYTES`, `spawn_warm`, `ui_state` durations); `src-tauri/src/commands.rs` (`full_buffer`, `set_trim`, `set_bass`, new `close_trim_editor`); `src-tauri/src/lib.rs` (register); `src/lib/api.ts`; `src/components/TrimEditor.tsx` + its test.

**Interfaces (engine):**
- Fields: `cache: BufferCache` now holds **play buffers**; `cut_for: HashMap<String, (Option<Trim>, f32)>` records each cached entry's tag (keep it in sync on every cache insert/remove/eviction — read the tag only when `cache.contains(id)`, and prune stale keys with `retain(|id, _| cache.contains(id))` the way `trimmed` does today); `editor: Option<(String, DecodedBuffer)>`. Remove the `trimmed` map.
- `play_file(&mut self, id, vol, path, trim, bass)` — same signature. Hit: cache has `id` and `cut_for[id] == (trim, bass)` → play it. Miss: `full` = editor slot if it is this id, else `decode_file(path)`; `play = bass_boost(&apply_trim(&full, trim), bass)`; `cache.insert(id, play)` (may evict) and record the tag. The full decode is dropped unless it is the editor slot.
- `insert_cached(&mut self, id, tag: (Option<Trim>, f32), buffer) -> bool` — for warming; never evicts (same rule as today); records the tag.
- `is_cached(id)` — unchanged meaning (any play buffer cached).
- `cached_duration(&self, id, trim: Option<Trim>) -> Option<f32>` — the cached buffer's `duration_secs()` when the cached tag's trim equals `trim`, else None.
- `editor_buffer(&self, id) -> Option<DecodedBuffer>` — the editor slot if it holds `id` (replaces `cached_buffer`).
- `set_editor(&mut self, id, full: DecodedBuffer)` — replaces the slot (replaces `cache_buffer`).
- `close_editor(&mut self)` — clears the slot.
- `preview(id, path, trim, vol, bass)` — full = editor slot if this id, else decode (and do not cache it); plays `bass_boost(apply_trim(full, Some(trim)), bass)` under `PREVIEW_ID` as today.
- `set_trim(id, trim)` / `set_bass(id, bass)` — drop the cached entry (and tag) when the tag differs.
- `invalidate(id)` — drop the cached entry, its tag, and the editor slot if it holds `id`.

**Interfaces (Tauri):**
- `spawn_warm`: for each id not cached, read path, `trim`, `bass` under a short lock; outside the lock `decode_file` → `bass_boost(&apply_trim(&full, trim), bass)`; then under the lock, if the sound still exists, is not cached, and its trim/bass are unchanged, `insert_cached(id, (trim, bass), play)`; stop when it returns false (cache full), as today.
- `full_buffer`: use `engine.editor_buffer(id)`; on a miss decode outside the lock and `engine.set_editor(id, buffer.clone())` if the sound still exists.
- `set_trim` / `set_bass`: after the change, `spawn_warm(ctx.shared.clone(), Some(vec![id]))` so the next play is instant (import `spawn_warm` from state like other commands do).
- New `#[tauri::command] pub fn close_trim_editor(ctx: State<'_, Ctx>)` → `lock(&ctx.shared).engine.close_editor();` registered in lib.rs.
- `CACHE_BYTES = 200 * 1024 * 1024` with a one-line comment: 16-bit samples, 10-minute 48 kHz stereo link ≈ 110 MB still fits.
- UI: `api.closeTrimEditor = () => invoke<void>("close_trim_editor")`; TrimEditor calls it in a `useEffect` cleanup that runs once on unmount (`useEffect(() => () => { void api.closeTrimEditor(); }, [])`), so every close path (Save, Cancel, Esc, import done, error) frees it.
